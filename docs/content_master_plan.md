# Content master plan — A1.1 → C2.2

**Status: DRAFT for approval. Nothing has been built.**

Goal: make every module a complete, certification-grade syllabus, with the
teaching content carried by each quiz's "How it works" panel (the Help Memory)
in real depth — rules, examples, tables, memory aids, the trap for English
speakers, and what exam task it feeds. Where the syllabus needs a quiz we do
not have, add the Help Memory now and a **placeholder exercise**; the exercises
get built later.

This plan was produced by testing the current course (214 quizzes, 12 modules)
against the official inventories and the leading textbooks. §1 says what we
checked against, §2 what the gap analysis found, §3 the module-by-module
master table, §4 what a "luxury" Help Memory contains and the schema it needs,
§5 the build order, §6 the decisions you need to make.

---

## 1. What the course was tested against

Primary sources, read in full where they are inventories. Every level A1–C2 now has a Goethe-authored document behind it; C1 has two, because the exam was rebuilt in 2024.

| Source | What it gives us |

| **Goethe-Zertifikat A1 Wortliste** | The 10 A1 theme areas, the **13 Wortgruppen** (numbers, date, clock, time spans, weekdays, times of day, months, seasons, currency, measures, countries/nationalities, colours, compass points), ~650 words. |

## 2. Findings — where the course is and isn't certification-complete

**The skeleton is right.** The existing plan's "one big rock per module", spiral of cases → endings → Konjunktiv → passive, and the five-type skill mix all survive contact with the sources. Nothing needs to be torn down.

**Three systematic problems, though:**

### 2.1 Structures sit one level too late

The official A1/A2 inventory and Menschen put several things earlier than we do. A learner sitting Goethe A1 today would meet these in the exam having never seen them here:

| Structure | Official level | Currently in course |
|---|---|---|
| Perfekt (receptive, ~15 verbs: *arbeiten, bleiben, essen, fahren, fragen, glauben, haben, lesen, lernen, machen, schlafen, sehen, passieren, trinken, verstehen*) | **A1** | A2.1 |
| Imperativ du / ihr / Sie | **A1** | A2.2 |
| Präteritum *war / hatte* (1st & 3rd person) | **A1** | A2.1 |
| Konjunktiv II as fixed politeness (*ich hätte gern, könnten Sie, ich würde gern*) | **A1** (lexical) | B1.1 |
| Dativ pronouns with *helfen / danken / gehören / es geht* (*mir, dir, Ihnen*) | **A1** | A2.1 |
| Lokale Präpositionen *an, auf, aus, bei, in, nach, von, vor, unter* (Wo?) | **A1** | A2.1 (as "Dativpräpositionen") |
| Temporale Präpositionen *um, am, im, von … bis, ab, für, nach, vor* | **A1** | scattered |
| Plural der Nomen (the 5 patterns) | **A1** | nowhere |
| Adjektivdeklination after def./indef. article (Nom/Akk/Dat) | **A2** (Menschen A2 L4/5/9) | B1.1 |
| Konjunktiv II *könnte / sollte* for suggestions & advice | **A2** (Menschen A2 L7) | B1.1 |
| Passiv Präsens (receptive) | **A2** | B1.2 |
| Präteritum regular + *kommen / geben / finden / sehen*; Modalverben im Präteritum | **A2** (Menschen A2 L20/24) | B1.2 |
| Relativsätze Nom/Akk | **A2** (Menschen A2 L23) | B1.1 |
| Indirekte Fragen (*ob*, W-Wort) | **A2** (Menschen A2 L16) | B2.1 |
| Verben mit Präposition + *da-/wo-* Komposita | **A2** (Menschen A2 L18) | B2.1 |
| Genitivpräpositionen *trotz / wegen*; *obwohl / trotzdem* | **B1** (Menschen B1 L4/12/13) | B2.2 |
| Passiv mit Modalverb; Passiv Perfekt | **B1** (Menschen B1 L21/22) | B2.1 |
| Konjunktiv II Vergangenheit — irreale Wünsche (*Hätte ich doch …!*) | **B1** (Menschen B1 L10) | B2.2 |
| Plusquamperfekt + *nachdem / bevor / während* | **B1** (Menschen B1 L8/11) | nowhere |
| Partizip I / II als Adjektiv | **B1** (Menschen B1 L14) | B2.1 |
| Modalpartikeln *denn / doch / eigentlich / ja* | **B1** (Menschen B1 L19) | B2.2 |
| Passiversatz (*-bar, sich lassen, sein + zu*) | **B2** (Sicher B2 L10) | C1.1 |
| Verweiswörter / Textkohäsion | **B2** (Sicher B2 L3) | C1.2 |
| Subjektives *sollen* | **B2** (Sicher B2 L8) | C1.2 |
| Nominalisierung (basic types) | **B2** (Sicher B2 L8) | C1.1 |

Fix: **introduce earlier, consolidate where it is now.** The spiral principle already says "intro → consolidation → advanced"; we just haven't put the intro rung in. This is the single biggest content change.

### 2.2 Whole categories are missing

- **The B2 core is verbal ↔ nominal transformation.** Sicher! B2 dedicates a section per lesson to it (kausal, temporal, konditional, konzessiv, konsekutiv, modal, adversativ — each as Konnektor *and* Präposition), and Goethe B2 / telc C1 test exactly this. We have the connectors but never the nominal counterparts (*aufgrund, dank, aus, vor, bei, trotz, infolge, durch, ohne, statt*) nor the transformation itself. **Six new quizzes.**
- **Wortbildung is thin.** The official inventory lists it at A1 (*-er, -ung, -in*, Komposita, *un-, -los, -bar*); Sicher B2 has it in every lesson (noun suffixes → gender, prefixes, *-weise*, negation prefixes, Fugen-s). We have two quizzes at C1.2. Needs a strand from A1.2 up.
- **Zustandspassiv, *von* vs *durch*, subjektlose Passivsätze, Futur II** — B2, absent.
- ***lassen* (4 meanings), Verbverbindungen with Doppelinfinitiv (*sehen / hören / lassen / gehen*)** — B2, absent.
- **Adjektive / Nomen mit Präposition** (*stolz auf, Bedürfnis nach*) — B2/C1, absent.
- **Adverbiale Nebensätze as a system** (temporal, kausal, final, konditional, konzessiv, konsekutiv, modal, adversativ, komparativ) — C1/C2 in Erkundungen; we have pieces but never the map.
- **Verben mit Präfixen: trennbar vs untrennbar** (*úmfahren / umfáhren, übersetzen, durchschauen*) — C1/C2, absent.
- **Präpositionen der Schriftsprache & Behördensprache** (*kraft, zwecks, gemäß, laut, zufolge, binnen, ungeachtet, seitens, mittels, anhand*) — C2 in Erkundungen, absent.
- **Umformulierung as a trained skill** — Goethe C2 Schreiben Teil 1 is literally "rewrite this text to these constraints" (nominal↔verbal, aktiv↔passiv, Relativsatz↔Partizip, direkt↔indirekt). We have "Paraphrase" once at C2.2; it needs to be a strand from B2 up.
- **Apposition & Genitivattribut chains, Genderneutrale Personenbezeichnungen, Valenz (Verben & Ergänzungen)** — C1/C2, absent.
- **The Wortgruppen**: countries/nationalities/languages, measures & weights & currency, compass points, ordinals & dates as spoken (*der erste März, zwölfter Vierter*) — A1, only partly present.

### 2.3 The "How it works" panels are notes, not lessons

Today every quiz has an intro of 50–250 characters and 1–3 tips. The best is ~250 characters. That is a reminder for someone who already knows the rule. The plan (§6 memory-aid toolkit, Rule B three layers, Rule C completeness) already asks for more, and Rule B's third layer — the table — was only restored last week. §4 defines the new standard.

## 4. The Help Memory standard ("luxury of detail")

### 4.1 What every panel contains

Seven layers, in this order. The first four are mandatory for every quiz; the last three are mandatory for every grammar quiz and optional for skills quizzes.

1. **The idea** — 2–4 sentences in plain English. What this is, why German does it, the one thing to hold on to. *(exists today as `intro`, but at ~150 characters; target 400–700.)*
2. **Rule cards** — 3–6 cards. Each: a title, the rule in one or two sentences, **2–3 examples in German with the English underneath**, and where relevant the **E# trap** (the English-speaker error from the contrastive spine). *(exists today as `tips`, 1–3 short ones; target 3–6 with examples.)*
3. **The reference table** — the declension/conjugation/connector table. Derived automatically for grid quizzes (done last week); **authored** for everything else (a connector list with meaning + word-order effect; a preposition table with case + example; a Konjunktiv paradigm).
4. **Words you need** — 10–15 items with article, plural and meaning, gender-coloured. Derived from the grid for fill-ins; authored for the rest. *(the vocabulary list added last week is the seed of this.)*
5. **How to remember it** — one or two memory aids from the plan's §6 toolkit (the gender colours, "the conjunction kicks the verb to the back", TeKaMoLo, "würde is always safe", etc.).
6. **In context** — a 3–5 sentence mini-text or dialogue using the structure naturally, with a play button, so the learner hears it before drilling it.
7. **In the exam** — one line: which Goethe/telc task this feeds (*"Goethe B2 Lesen Teil 4 fills exactly these gaps"*; *"telc C1 Sprachbausteine"*; *"C2 Schreiben Teil 1: you will be asked to rewrite a text this way"*). Brand names appear here only as factual exam references, never in titles — per the IP rule.

Plus, for fill-ins: **Common mistakes** — the three errors English speakers make on this item, each with the wrong form, the right form and why.

### 4.2 Schema change

`QuizHelp` today: `{ intro?, tips?: {title?, text, kind?}[], colorByGender? }`.

Proposed `QuizHelp` v2 (additive — every existing quiz still validates):

```
help: {
  intro: string;                       // layer 1, now required, ≥ 300 chars
  tips: {                              // layer 2
    kind: 'rule' | 'mnemonic' | 'warning' | 'exam';
    title: string;
    text: string;
    examples?: { de: string; en: string }[];   // NEW
    trap?: string;                              // NEW  (E# id or free text)
  }[];                                 // ≥ 3 for grammar quizzes
  table?: {                            // layer 3, authored when there is no grid
    caption?: string;
    columns: string[];
    rows: { cells: string[]; gender?: string }[];
  };
  vocab?: { de: string; article?: string; plural?: string; en: string }[];  // layer 4
  remember?: string[];                 // layer 5
  context?: { de: string; en: string };            // layer 6 (played by TTS)
  exam?: string;                       // layer 7
  mistakes?: { wrong: string; right: string; why: string }[];
  colorByGender?: boolean;             // unchanged
}
```

`QuizBase` gains `status?: 'live' | 'placeholder'`.

### 4.3 What the placeholder is

A placeholder quiz has a **complete Help Memory** and a **minimal exercise**: for `fillBlank`, a grid of 6–8 subjects × the categories with real answers (that *is* the reference table, so it must exist anyway) and **no authored sentences** — the existing template engine generates them; for skills quizzes, a short real passage/phrase set of half the normal length. The page shows a small "preview — exercise being expanded" line under the title. Placeholders **count in the ladder** (the content is real) but are **excluded from the printable worksheet** until they go live. The gate test relaxes the ≥ 10-sentence rule only for `status: 'placeholder'`.

### 4.4 Gate tests (enforced, so this cannot regress)

- every quiz: `intro ≥ 300 chars`, `tips.length ≥ 3` (skills quizzes ≥ 2), every tip has `examples` unless `kind === 'exam'`;
- every grammar quiz: `table` present (derived or authored), `vocab ≥ 8`, `remember ≥ 1`, `context` present, `mistakes ≥ 2`;
- every module: the structures in §3's master table appear in at least one quiz's `help` (a `covers: string[]` field on each quiz, checked against a per-module list in `docs/`) — this is how "we are covering all the content necessary" becomes a test rather than a hope.

### 4.5 Where it is shown

- **Quiz page** — HelpMemory renders all seven layers; auto-opens on first visit (as now); the layer order above is the reading order.
- **Worksheet/PDF** — layers 1, 2, 3, 4, 5 print above each quiz's exercises (2 and 3 already do; extend).
- **A per-module "Syllabus" page** (new, `/course/de_cert_a1/level/A1.1`) — the master table for that module: what it teaches, every quiz, the exam it prepares for. This is the learner-facing version of §3 and the place a learner checks "have I covered everything for A1?".
